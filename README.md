# 我的游戏 (My Games)

这是一个使用 C++ 编写的经典命令行游戏集合，包含多个有趣的小游戏。

## 游戏列表

本项目包含以下游戏：

### 1. 2048
经典数字益智游戏。
- **目标**：通过合并数字方块，得到 2048 或更高的分数
- **操作**：方向键控制方块移动
- **特点**：记录最高分和步数

### 2. UNO
经典纸牌游戏 UNO 的命令行版本。
- **玩法**：出牌匹配颜色或数字，最先出完手牌获胜
- **功能**：支持多种卡牌类型（+2、转向、跳过、+4等）
- **模式**：支持双人游戏

### 3. Clock (Clock Solitaire)
时钟纸牌接龙游戏。
- **规则**：将牌按特定顺序移动到时钟位置
- **目标**：成功放置所有纸牌

### 4. Fly Bird
类似“愤怒的小鸟”的飞行躲避游戏。
- **玩法**：控制小鸟躲避障碍物
- **操作**：按键控制上升，松手下落
- **特点**：多种皮肤可选

## 环境要求

- C++ 编译器（支持 C++11 或更高版本）
- Windows 操作系统（代码中使用 Windows API）

## 编译运行

每个游戏都有独立的源文件，可以单独编译运行：

```bash
g++ -o 2048.exe main/cpp/2048/2048.cpp
./2048.exe
```

其他游戏同理。

## 操作说明

- **2048**：使用方向键移动方块
- **UNO**：按照提示选择操作
- **Clock**：按照提示进行游戏
- **Fly Bird**：按空格键或方向键控制

## 项目结构

```
main/cpp/
├── 2048/2048.cpp      # 2048 游戏
├── UNO/UNO.cpp        # UNO 游戏
├── clock/Clock.cpp   # 时钟接龙游戏
└── flyingbird/Fly Bird.cpp  # 飞行游戏
```
